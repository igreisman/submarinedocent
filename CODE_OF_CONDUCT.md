# Code Of Conduct

## Our Standard

This project expects contributors to be respectful, direct, and constructive.

Examples of behavior that contribute to a healthy environment:

- giving actionable technical feedback
- assuming good intent while reviewing changes critically
- documenting decisions clearly
- respecting editorial, historical, and legal constraints around source material

Examples of unacceptable behavior:

- harassment or personal attacks
- discriminatory language or behavior
- deliberately disruptive or bad-faith participation
- publishing private security issues or sensitive operational details irresponsibly

## Enforcement

Project maintainers may remove, edit, or reject contributions and interactions that violate this code of conduct.

## Reporting

Report conduct problems through the same private maintainer channel used for project operations, not in public issue threads where escalation would create more harm.
