War Patrols

Write and publish the USS Pampanito war patrol pages. Each tab corresponds to one of the five patrols. A green dot on a tab means that patrol already has saved content.

  • Upload .docx — converts a Word document to HTML in your browser. No content is sent to any server during conversion.
  • Upload .html — loads an existing HTML file directly into the editor. If the file has a <body>, only its contents are used.
  • Edit HTML — toggles between WYSIWYG and raw HTML view. Use HTML view to fix tables or complex formatting.
  • Save — writes the content directly to the patrol detail page file.
  • View page — opens the published patrol page in a new tab (appears after first save).
