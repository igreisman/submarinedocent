Categories

Manage the full FAQ category list here. You can reorder categories, rename them, edit and reorder the FAQs inside each one, add new categories, delete categories, and add FAQs.

  • Reorder categories: drag a category card — by its title or anywhere on the row — to change the order used on the public FAQ page. (The Edit, Add FAQs, and Delete buttons don't start a drag.)
  • Edit opens a panel for that category where you can rename it and manage its FAQs:
    • Change the Category name and click Save. Renaming also updates every FAQ assigned to it.
    • Reorder FAQs by dragging a FAQ by its name; the new order saves automatically.
    • Click Edit on a FAQ to change its question and answer with the rich-text editor, then click Save — that one button saves both the category name and the open FAQ.
  • Add Category adds a new, empty category at the bottom of the list.
  • Delete removes a category and clears that category assignment from its FAQs (the FAQs themselves are kept).
  • Add FAQs opens a panel where you can add a single FAQ (type a question and answer) or bulk-import multiple FAQs from a .docx file. In the Word document, write each question in bold — the paragraphs that follow it (until the next bold line) become the answer.
